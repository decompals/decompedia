# Lego Star Wars 3 - The Clone Wars
## About
An in-progress decompilation of Lego Star Wars 3 for the Nintendo Wii.
The decompilation supports `SC4E64`, Rev 0 (USA) and `SC4P64`, Rev 0 (PAL), both of which are functionally equivalent.

The game contains a symbol mapfile on the disc, and found on [debugging.games](https://debugging.games/_files/Wii/[WII]%20LEGO%20Star%20Wars%20III%20-%20The%20Clone%20Wars%20(Europe)%20(En,Fr,De,Es,It,Da)%20(v1.00).7z)
